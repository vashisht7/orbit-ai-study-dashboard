The shapes you’ll see everywhere

B = batch (examples together) · T = sequence (tokens per example) · D = hidden size (numbers per token) · V = vocabulary size (possible token IDs).

Token IDs [B,T] → embeddings [B,T,D] → logits [B,T,V] → probabilities [B,T,V]

Example: B=2, T=4, D=8, V=100. Two four-token examples become [2,4,8] vectors, then [2,4,100] scores. Softmax runs over the last (vocabulary) axis. Padding makes lengths equal; a mask identifies padding.
